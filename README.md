# 📚 BookNest – Online Bookstore

BookNest is a modern and responsive online bookstore developed using **HTML, CSS, and JavaScript**. It provides a simple and user-friendly shopping experience where users can explore books, search by title or author, filter by category, and manage their shopping cart.

## ✨ Features

- **15 Books Collection:** Browse a collection of books with titles, authors, prices, and cover images.
- **Search Functionality:** Search books by title or author.
- **Category Filters:** Filter books according to their categories.
- **Shopping Cart:** Add books to the cart and manage selected items.
- **Quantity Controls:** Increase or decrease book quantities.
- **Remove Items:** Remove books from the shopping cart.
- **Automatic Price Calculation:** Calculate subtotal and total price dynamically.
- **Local Storage:** Preserve cart data even after refreshing the page.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling, layouts, and responsive design
- JavaScript – Search, filtering, cart management, and calculations
- Local Storage – Persistent cart data

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the **Live Server** extension in VS Code.
